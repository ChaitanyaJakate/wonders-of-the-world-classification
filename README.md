# Wonders of the World Image Classification

Image classification using TensorFlow/Keras and deep learning.

## Models

- Custom Convolutional Neural Network (CNN)
- EfficientNetB7 transfer learning with a frozen ImageNet-pretrained backbone

## Dataset

[Kaggle — Wonders of the World Image Classification](https://www.kaggle.com/datasets/balabaskar/wonders-of-the-world-image-classification)

The dataset contains 12 classes. The experiments used an 80/20 training-validation split.

## Results

| Model | Best observed validation accuracy |
|---|---:|
| Custom CNN | 33.16% |
| EfficientNetB7 | 98.96% |

These are validation results, not independent test-set results.

## Technologies

Python, TensorFlow, Keras, CNN, Transfer Learning, EfficientNetB7, Google Colab.
